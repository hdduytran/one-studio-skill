# 3D: Three.js, React Three Fiber, Drei, Postprocessing, Rapier

Enable with `init_project.sh … --with three`. Adds `Scene3D` (hero objects + bloom) and `PhysicsPlayback` (baked Rapier).

## Remotion rules for 3D
- Wrap everything in `<ThreeCanvas width={width} height={height}>` from `@remotion/three`.
- **Never `useFrame()`**. Compute positions/rotations from `useCurrentFrame()`. `ThreeCanvas` re-renders the scene once per frame for you.
- Any `<Sequence>` inside the canvas needs `layout="none"`.
- Drei helpers with their own clocks (`Float`, `OrbitControls autoRotate`, `Sparkles`, `Stars` speed, `MeshWobbleMaterial`, `useAnimations` for glTF clips) must be frozen (`speed={0}`) and driven manually. For glTF animation clips: `mixer.setTime(frame / fps)` in a `useLayoutEffect`.
- Load models/textures with `useGLTF(staticFile(...))` / `useTexture(...)` inside `<Suspense>` — the render waits.
- Renders use software WebGL in headless Chrome: keep poly counts and shadow maps moderate; `remotion.config.ts` sets `setChromiumOpenGlRenderer("angle")`. Try `--gl=swangle` or `--gl=egl` if a machine renders black.

## Lighting without network
`<Environment preset="city">` downloads an HDR from a CDN at render time — fails offline and is a render-time network dependency. Use:
```tsx
<Environment resolution={256}>
  <Lightformer form="rect" intensity={4} position={[0, 5, -5]} scale={[10, 5, 1]} />
  <Lightformer form="ring" intensity={2} color="#6C8CFF" position={[5, 2, 3]} scale={3} />
</Environment>
```
or a local file: `<Environment files={staticFile("hdri/studio.hdr")} />`.

## Camera moves
Interpolate camera position from frame and pass it via the `camera` prop, or use a `<PerspectiveCamera makeDefault position={[x,y,z]} />` from Drei with frame-driven values. Classic moves: push-in (z 14→9 with `ease.out`), orbit (`x = r*sin(t)`, `z = r*cos(t)` + `lookAt(0,0,0)`), crane (y up + tilt down).

## Postprocessing (React Postprocessing)
```tsx
<PostFxWarmUp />
<EffectComposer>
  <Bloom intensity={0.6} luminanceThreshold={0.6} mipmapBlur />
  <Vignette darkness={0.5} />
</EffectComposer>
```
**Gotcha found in testing:** EffectComposer creates its passes in an effect, so the first frame drawn after mount is blank. In a parallel render every chunk starts with a fresh mount → a black flash every N frames. `PostFxWarmUp` (in `Scene3D.tsx`) holds the frame with `delayRender`, waits two animation frames, calls `advance()` and continues. Copy it into any scene using `EffectComposer`.

Good effects for motion design: Bloom (glow on emissive/bright), Vignette, DepthOfField (focus pulls — drive `focusDistance` from frame), ChromaticAberration (glitch hits, 2–4 frames), Noise (film grain, `premultiply`).

## Physics (React Three Rapier) → bake it
`<Physics>` from `@react-three/rapier` steps on real time. Frames rendered out of order or in parallel can't reproduce it. Bake instead:
```bash
npm i -D @dimforge/rapier3d-compat@0.19.2
node <skill>/scripts/bake_physics.mjs . sim.json          # → public/physics/sim.json
```
`sim.json`:
```json
{ "fps": 30, "seconds": 3, "ground": { "y": -1.5 },
  "bodies": [ { "id": "logo", "shape": "box", "size": [2, 1, 0.4], "position": [0, 6, 0], "angularVelocity": [0, 3, 0] } ],
  "spawn": { "count": 20, "shape": "box", "size": [0.6, 0.6, 0.6], "area": [5, 2], "height": [3, 10] } }
```
Then use `PhysicsPlayback` (`props: { "src": "physics/sim.json" }`) or read `track[frame][body]` in your own scene. The bake is seeded and deterministic (same input → byte-identical output). Use React Three Rapier itself only for interactive previews in the Studio, not for final renders.

## Recipes
- **Logo extrusion**: SVG → Drei `<Svg>` for flat, or `SVGLoader` + `ExtrudeGeometry` for depth; rotate y from -30°→0 with `ease.out`, bloom on an emissive edge.
- **Product turntable**: glTF + `ContactShadows` (static `frames={1}`) + orbit camera; 1 rotation every 6–8s.
- **3D text**: Drei `<Text3D font={staticFile("fonts/inter_bold.json")}>` (typeface JSON, bundle locally) + `<Center>`.
- **Data in 3D**: bars as boxes whose `scale.y` comes from `interpolate` with stagger.
