# Story core

Read at gate 1. The Story core is what makes a script sound like a person who did the work. A model cannot invent it, so ask the user for what is missing (max 3 questions) and never fabricate a person, quote or number.

## The eight fields

| Field | Test it must pass |
|---|---|
| Angle | One sentence saying what this video says that others do not. "Accountants do not hate Excel, they hate 5 pm on the last Friday of the month." |
| Real person | Someone specific, somewhere, with a problem. "Lan, sole accountant for three shops." Not "users". |
| Tension | What is at stake or in conflict? "The boss needs the numbers by 9 am Monday." |
| Misconception | What does the viewer believe that is wrong? "Accounting software is for big companies." |
| Details only this topic has | Three concrete things from research. If a detail would fit any other video, it is not one. |
| Point of view | Where do we stand, in what voice? Pick one tone from `tones.md`. |
| Promise and payoff | What the title promises, and the second it is paid. "Cut 3 hours" is paid by a clock at 0:40. |
| Sources | Every number and real-world claim gets a source and a date. |

## Quick tests

- Prop test: if a detail could appear unchanged in a video about another product, it came from the template, not the source. Replace it.
- Delete test: remove the product name. If the angle still reads as a real claim, keep going; if it turns into a slogan, the angle is empty.
- Person test: could you picture the person's desk? If not, you have a persona, not a person.

## Angle examples

- Weak: "How GPS works." Strong: "Your phone never talks to the satellites; it only listens, and the delay is the whole trick."
- Weak: "Why our tool is fast." Strong: "We stopped trusting our own benchmark after it ran on a laptop in a quiet room."

## When the user has no angle

Offer three candidate angles built from the research, each with the surprising detail behind it, and let the user pick or merge. Do not write the script around a blank angle: the result is a feature list.
