# Beat outline

Use at gate 2 after the angle is fixed and before any sentence is written. Output: 5-9 beats in `script.md` scene order, one sentence each.

## But / therefore

Every joint between beats is "but" or "therefore" (Parker and Stone's rule). "And then" is a list, not a story; the lint allows at most one "và rồi / rồi thì / and then" in the whole script.

Bad: "GPS uses satellites, and then the phone measures time, and then it computes position."
Good: "Your phone seems to talk to satellites, but it only listens. Therefore the delay of each signal is all it has. But one delay gives only a circle, therefore it needs a fourth satellite."

Test: read only the connectors. If you can replace each with "and then" without changing the meaning, the causality is missing; find what makes the next beat necessary.

## Shape and share of runtime

Playbooks give exact percentages; this is the default skeleton.

| Part | Share | Job |
|---|---|---|
| Hook | 5-10% (first 3 s) | Stake, question or odd fact; pays the title's promise on a clock you can name |
| Misconception or problem | 15% | The thing the viewer believes or suffers |
| Turn | 10% | The "but" that changes the situation |
| Body (2-5 beats) | 50-60% | One dominant image per beat; concrete example before rule before name |
| Proof or payoff | 10% | The promised result, visible |
| Close | 5% | One thing to do, or a loop back to the first image |

## Re-hook

Videos over 3 minutes need a re-hook every 60-90 s: an open question, a reversal, a new stake. The first minute decides who stays; a beat around minute 3 wins them back. Shorts: each beat must earn the next second.

## Open loop

Promise the best item or answer early, deliver it late. Do not hide it: "In the last scene you will see why four, not three" works; withholding without a promise reads as stalling.

## Visual abstract (before words)

Per beat, name one concrete image, not an icon: "a crumpled invoice that flattens as the score rises", not "a gear". The picture is chosen first, the voice explains it. Write it as `> visual:` when the script is drafted.

## Cut

The script runs shorter than the video: Vietnamese about 2.8 words/s, English about 2.5. After the draft, delete the weakest whole beat before shaving words everywhere.
