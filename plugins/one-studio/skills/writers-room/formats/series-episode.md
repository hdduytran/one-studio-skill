# Format: series-episode

One episode in a running series. Layer on any playbook; continuity is the added job.

## Hook

- Open with a one-sentence recap of the last episode, spoken over the shared motif, not a montage.
- Then the new question for this episode, within 10 seconds.
- Reuse the series intro sting only if it is under 3 seconds.

## Beat length

- Keep the same beat length and pace as the earlier episodes so the series feels like one voice.
- The world file and the motif (colour, object, camera move) are reused; if a world changes, the first beat shows why.
- Do not retell facts established earlier; link back by name.

## Ending

- Resolve this episode's question fully; the episode must stand alone.
- End with one open question for the next episode, seeded by something shown in this one.
- Say when the next episode is available only if the date is fixed.

## On-screen text

- Episode number and title on a fixed position and style.
- Recurring labels (source, opinion) look the same every episode.

## Captions

- Same style, font, colour as earlier episodes.
- Recurring names and terms spelled consistently across the series; keep a glossary in the project notes.
