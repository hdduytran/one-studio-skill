# Visual modes

A mode is a way of staging a scene, not a scene type (only `screen-cinema` adds the `screen` type). Set `mode` on the storyboard scene. Load at most 3 mode files per video.

- `world-camera` · concepts, scale, systems, timelines as one continuous shot · pairs with `diagram`, `explainer`, `text` (requires world tools)
- `match-cut-motif` · hand a shape or a running motif from one scene to the next · pairs with any type
- `screen-cinema` · real interface with click-following zoom · pairs with `screen` (needs `services.capture`)
- `desk-collage` · paper, tape, clippings, hand-made judder · pairs with `text`, `diagram`
- `exploded-cutaway` · parts and a flow through a mechanism · pairs with `diagram`, `explainer`, `3d`
- `kinetic-type` · words as the picture, timed to the voice · pairs with `text`
- `split-compare` · two things, same task, same clock · pairs with `diagram`, `data`
- `archive-documents` · maps, photos, records, dated and sourced · pairs with `text`, `diagram`
- `data-story-motion` · data moving with the narration · pairs with `data`, `lottie`
